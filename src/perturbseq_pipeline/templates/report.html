4. Perturbation enrichment across clusters

Section 3 asked whether each guide knocked its target down. This section asks the follow-on question: did losing that gene push cells into a particular transcriptional state? Every target is tested against every cluster with Fisher's exact test{% if enrichment.stratified %}, stratified by {{ enrichment.stratify_by }} (Cochran-Mantel-Haenszel) so that differences in cluster composition between lanes cannot masquerade as a perturbation effect{% endif %}, with BH-FDR across all {{ enrichment.n_tests }} pairs.

Why an exact test. {{ enrichment.pct_small }}% of the expected counts in this table are below 5, because rare clusters hold few reference cells. That makes chi-square residuals unreliable per cell, so it is used only as a global screen and each pair is tested exactly.

Reference. Results are reported against {{ enrichment.controls_described }}; ranking and hit calling use {{ enrichment.control_label }}. {{ enrichment.n_low_power }} pair(s) are flagged low-power, where the reference contributes too few cells in that cluster to trust the odds ratio.

5. Per-cell perturbation response

Sections 3 and 4 treat all cells carrying a guide as one group. But a perturbed population is rarely uniform: some cells are genuinely knocked down while others escape. This section scores each cell individually using PS_python (pertps {{ ps.version }}), the lab's implementation of the scMAGeCK perturbation score — it learns the expression signature of each perturbation and projects every cell onto it.

Each perturbed cell is placed in one of four quadrants by its score (cut at {{ ps.threshold }}) and by the target's own expression relative to the control median:
  • Successful knockdown — high score, low expression.
  • Escaper — high score, but the gene is still expressed.
  • Non-responder — low score, normal expression.
  • Low signal — low score and low expression; uninformative.

6. lochNESS neighbourhood enrichment

Section 4 asks whether a perturbation is over-represented in a discrete cluster. lochNESS, ported from pertTF, asks the same question continuously and without clusters: for every cell it takes the share of that cell's {{ lochness.k }} nearest neighbours carrying a given perturbation, divides by that perturbation's share of the whole dataset, and subtracts one.

0 means the perturbation appears among a cell's neighbours exactly as often as its overall frequency would predict. Above 0 means locally over-represented, below 0 under-represented. Because the score is per-cell, it maps where in the manifold a perturbation accumulates — including structure that sits inside one cluster, or straddles two, which the cluster test in section 4 cannot see.
